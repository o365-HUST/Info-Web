# Club photo assets

Hero and About use **AI stand-in photos** so you can see the shot type to capture. Replace with real club JPEGs using the **same filenames** — no code change needed if names match.

Department card art and blog thumbs are separate illustration assets (not empty SVG slots).

| Hero full-bleed | `hero/hero-campus.jpg` | Campus plaza / outdoor club atmosphere | 16:9 or 3:2, edge-to-edge |

## Guidelines for real photos

- Prefer **real** club members, desks, and events.
- Natural light or event lighting; avoid heavy filters.
- Hero should read as place/atmosphere; faces can be secondary.
- After dropping real `.jpg` files over the stand-ins, hard-refresh the site.
